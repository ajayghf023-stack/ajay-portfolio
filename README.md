# AJAY.DEV

A responsive personal portfolio for Ajay, a Full Stack Developer and B.Tech Computer Science and Engineering (Data Science) student. The site explores software engineering, cybersecurity, and space technology through a mission-control-inspired interface.

## Development

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

The hero's Three.js scene is lazy-loaded on supported desktop browsers. Smaller screens, browsers without WebGL, and reduced-motion preferences use a lightweight static scene instead. Mission Control is a local simulation; its readouts are not real spacecraft telemetry.

Replace the placeholder email in `src/sections/Contact.jsx` with a preferred contact address. The GitHub and LinkedIn links currently point to their generic homepages because profile URLs were not provided.
